# Readme Doctor

为 GitHub README 做一次发布前体检。

Readme Doctor 可以读取公开 GitHub 仓库，检查 README 中的项目介绍、安装步骤、使用示例、截图、许可证、贡献指南等内容，并给出 100 分制评分与改进建议。

## 功能

- 支持 GitHub 完整链接和 `owner/repository` 简写
- 12 项 README 与仓库资料检查
- 100 分制评分和优先改进建议
- 无需登录，不上传代码
- 响应式网页界面

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 技术栈

- React
- TypeScript
- Vite
- GitHub REST API
